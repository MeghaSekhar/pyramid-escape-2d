# 🛕 Pyramid of 20 Trials (2D Puzzle Game)

A lightweight 2D browser-based puzzle adventure game built with HTML5 Canvas and JavaScript. Players guide Maya and Leo through 20 ancient chambers inside a sealed pyramid.

🎮 **[Play Live Demo Here](https://MeghaSekhar.github.io/pyramid-escape-2d/)**

## 🌟 Features & Architecture
- **Zero External Dependencies:** Built using vanilla JavaScript and HTML5 Canvas.
- **Lighting Engine:** Procedural Canvas radial gradient flickering for atmospheric lighting.
- **Logic & Puzzle Engines:** Features state-machine puzzles including volume transfers, pitch sequences, and riddle validations.

## 🕹️ How to Play
1. Open the live demo link in any modern web browser.
2. Interact with the chamber controls at the bottom of the screen to solve each puzzle.
3. Advance through the chambers to unlock the pyramid's exit.
